# Verdicspec project artifacts

This directory stores the durable artifacts produced by the Verdicspec for the host project.

- `product-brief.md`: product problem, users, outcome, and smallest useful slice.
- `system-context.md`: current system, boundaries, dependencies, and invariants.
- `technology-inventory.md`: detected technology and confirmed commands.
- `specifications/`: approved change specifications.
- `decisions/`: architecture and product decisions.
- `plans/`: implementation plans.
- `reports/`: verification, spike, review, and release reports.

Artifacts are evidence and decision records. They should evolve with the product and must not claim checks that were not executed.
