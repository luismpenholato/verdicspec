# Observability checklist

- [ ] What operational question must be answered?
- [ ] Is the relevant event logged with structured fields?
- [ ] Are secrets and personal data excluded or redacted?
- [ ] Is success measurable with a counter or result metric?
- [ ] Is latency or duration measurable where relevant?
- [ ] Is failure classified consistently?
- [ ] Can a request or job be correlated across boundaries?
- [ ] Is the signal useful in the target environment?
